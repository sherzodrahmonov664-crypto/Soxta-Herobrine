═══════════════════════════════════════════════════════════════════════════════
                            🚀 TEZKOR BOSHLASH
═══════════════════════════════════════════════════════════════════════════════

1. TEZKOR_BOSHLASH.txt faylini oʻqing

2. Java 17+ oʻrnatilganini tekshiring:
   java -version

3. Compile qiling:
   Windows:   gradlew.bat build
   Mac/Linux: ./gradlew build

4. JAR faylni topik:
   build/libs/soxta-herobrine-1.0.0.jar

5. Minecraft mods folderiga qoʻying:
   Windows:   %APPDATA%\.minecraft\mods\
   Mac:       ~/Library/Application Support/minecraft/mods/
   Linux:     ~/.minecraft/mods/

6. Minecraft ishga tushiring!

1. SoxtaHerobrineClient.java
   - Mod ni initialize qiladi
   - Herobrine entity turini registratsiya qiladi

2. HerobrineEntity.java
   - Herobrine sifatida ishlovchi entity

   - Herobrine ni suratda chizadi

4. HerobrineManager.java
   - Herobrine lifecycle boshqaradi

   - Chase behavior
   - Teleportation logic
   - Lifetime va removal
