# Herobrine Texture Qoʻshish 🎨

## Texture Fayl Lokatsiyasi

```
src/main/resources/assets/soxta_herobrine/textures/entity/herobrine.png
```

Bu papkani yarating, agar yo'q bo'lsa!

## Texture Talablari

- **Format:** PNG (64x64 pixels)
- **Model:** Steve model (Player model)
- **Transparency:** Yo'q, to'liq opaque

## Scary Texture Yaratish

### Variant 1: Online Generator
1. https://www.needcoolshoes.com/banner ga o'ting
2. Steve skin tanlang
3. Scary qilib yuborish uchun:
   - Ko'zlarni **oq** yoki **qora** qiling
   - Yuzni **qorong'i** qiling
   - Terini **grimy** qiling
4. PNG sifatida yuklab oling

### Variant 2: Photoshop/GIMP
1. Default Steve skin yuklang
2. Ko'zlarni oq qo'yib qora ring chizing
3. Yuzga qorong'i varni qo'ying
4. 64x64 sifatida export qiling

### Variant 3: Hozircha Default Skin
Agar texture yo'q bo'lsa, mod default Steve skinni ishlatadi.

## Texture Papkasini Yaratish

Agar papka yo'q bo'lsa:

### Windows:
```
mkdir src\main\resources\assets\soxta_herobrine\textures\entity
```

### Mac/Linux:
```bash
mkdir -p src/main/resources/assets/soxta_herobrine/textures/entity
```

## Texture Qo'shgandan Keyin

1. `herobrine.png` faylni papkaga qo'ying
2. Qayta compile qiling:
   ```bash
   ./gradlew clean build
   ```
3. JAR ni mods folderiga qo'ying
4. Minecraft ishga tushiring
